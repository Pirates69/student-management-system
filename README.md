# Student Management System in C++

A simple console-based Student Management System developed using C++. This project uses Object-Oriented Programming (OOP) concepts and binary file handling to manage student records.

## Features

- Add new student records
- Display all student records
- Search for a student by roll number
- Update student details
- Delete student records
- Find the topper based on marks
- Store records in a binary file for persistence

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling (Binary Files)

## How to Run

1. Install a C++ compiler such as GCC.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Compile the source code:

   ```bash
   g++ -std=c++17 Student_Management_System.cpp -o student_system
   ```

5. Run the program:

   **Windows PowerShell:**
   ```powershell
   .\student_system.exe
   ```

   **Linux/macOS:**
   ```bash
   ./student_system
   ```

## Concepts Demonstrated

- Classes and objects
- Encapsulation
- Functions and control structures
- Binary file input/output
- CRUD operations (Create, Read, Update, Delete)
- Searching and finding the maximum marks
